Сюда кладём готовые mp3 с озвучкой радар-детектора. Имя файла и текст должны совпадать 1:1 с `AUDIO_MAP` в `js/radar-module.js`:

- `start.mp3` — «Соединение установлено»
- `1000.mp3` — «Через 1000 метров камера контроля скорости»
- `500.mp3` — «Внимание, камера контроля скорости 500 метров»
- `200.mp3` — «Камера контроля скорости, 200 метров, снизьте скорость»

Пока файла нет — модуль автоматически озвучивает текст через встроенный голос браузера (speechSynthesis). Как только файл появится в этой папке — он подхватится сам, без изменений в коде.
